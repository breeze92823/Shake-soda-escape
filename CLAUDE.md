# Shake Soda Escape

Three.js (vanilla) + Vite. The lobby (Roblox-style studded arena) and the player; look and feel ported from `C:\ThreeJS\Clean-leaves-for-loot\Clean-leaves-for-loot` (the reference — keep materials, lights, camera and controls in sync with it).

- `npm run dev` / `npm run build`. `VITE_DEV_MODE=true` skips the Bloxity SDK/CDN (see `.env.example`).
- All tunables in `src/config.js`. All Bloxity SDK calls go through `src/bloxity.js` and must never throw (SDK may be blocked). `GAME_SLUG` must match the slug registered on bloxity.io.
- `src/player.js` player singleton + kinematic movement (`floorAt` = single floor lookup over `addSolid` boxes; boxes taller than `STEP_UP` are walls). `src/camera.js` chase cam (own yaw/pitch, smoothed follow, eased wheel zoom, speed pull-back/FOV). `src/world.js` studded baseplate, sky shader + rainbow/clouds, sun + hemisphere lights (shadow box follows the player).
- `src/lobby.js` the lobby scenery + colliders, layout in `config.js` (`ARENA`, `TOWER`, `PORTAL`, ...): walls, numbered Soda Jump tower + launch pad, World 2 portal, Void Soda NPC, soda display (east: 5 front + 7 back items on a two-tier red platform, both tiers ramped, hovering items with sparkles), soda multiplier treadmills x1-x32 on a red platform (west), Top Soda / Top Rebirths leaderboards + FREE chest (south wall; placeholder standings). `src/textures.js` stud/checker canvas textures + `studBox` (world-metre UVs). `src/labels.js` billboard text sprites (in-world signs, not HUD). `src/input.js` WASD/arrows, Space, mouse look (pointer lock; right-drag fallback), wheel zoom, Esc = portal menu. `src/touch.js` phone controls.
- `src/hud.js` + `hud.css` DOM HUD laid out in 1920x991 reference space, scaled by `--s` (compact layout `.mob` on phones/small windows): system buttons, wins, Rebirth/Daily/Aura/Worlds tiles, x2 passes, soda total + level bar, soda packs (`SODA_PACKS`, `BOOST_PASSES` in config). Values from `src/state.js` (`state` + `notify()`, seeded from `HUD_START` placeholders). Rebirth tile opens `src/rebirth.js` (+ `rebirth.css`): Rebirth n vs n+1 (`REBIRTH` in config, `rebirth()` in state.js resets the level), Skip Rebirth toasts; open windows set `body.win-open` and Escape closes them (`win-close` event). Aura tile opens `src/aura.js` (+ `aura.css`): 8 `AURAS` (config.js), bought once with Wins only, one equipped at a time (`state.aura`), its `mult` multiplies soda gain (`auraMult` in state.js). No store yet: other buttons toast. `src/icons.js` inline SVG icons.
- `src/worlds.js` + `src/worldScenes.js` + `WORLDS` in config.js: 5 themed worlds behind the Summit (Candy Cloud Kingdom, Neon Cola Station, Frozen Soda Glacier, Volcano Lava Soda, Underwater Fizz Reef), chained: the 20K Summit in a world unlocks + warps to the next (`state.worlds` saved, `state.world` current). Each has its own sky/fog/light/floor (`space.setWorld`), colliders + zones tagged per world (`setBuildWorld` / `setActiveWorld` in player.js), `winsMult` / `sodaMult`, optional `gravity` / `grip` (ice). Worlds build lazily on first visit; portals are hold-E zones, the Worlds tile opens the travel window. The Summit plays `src/blackhole.js` (+ css): a black hole opens in front of the player, debris spirals in, the avatar is sucked in (spin/shrink via `blackhole.state`, applied in main.js), white->black flash, `enter()` the next world, then a "WORLD UNLOCKED <name>" banner. Away from the lobby the avatar is parked under the lobby floor for other players and remotes are hidden. Backend `WORLD_IDS` is kept in step by hand. `src/worldShop.js`: every world also gets the lobby's six treadmills (`buildShop`, same layout so `treadmillAt` works, world colours) and a 3-soda shelf (east, `WORLD_SODAS` in config.js: ids `<world>-1..3`, own unlock ladder, Wins prices rising per world; models in `sodaItems.js` default case). Backend `SODA_IDS` must list them.
- `src/avatar/`: Bloxity base rig (`public/avatars/player.glb`, procedural fallback), cosmetics + proportions loader, procedural animator.
- `src/avatar/heldCan.js` + `ANIM.hold`: every avatar holds an upright cola can in the right hand; `animator.js` `applyHold` layers the arm pose over every state.
- `src/interact.js` + `src/prompt.js`: "hold E" zones (`addZone`, `INTERACT.holdMs` = 2s, ring prompt; touch = tap-hold the prompt). The soda display pads are zones: hold E to equip -> `state.equipped` -> `HeldCan.setItem` swaps the hand model (`src/sodaItems.js` has the models) and the signs flip OWNED/EQUIPPED. `SODA_ITEMS` in config.
- `src/net.js` Colyseus link to `../Shake-soda-escape-backend` (room `world`): loads/saves the persisted `state` keys (`SAVED`: soda, wins, level/xp, rebirths, equipped/owned/passes/auras/aura, record, sodaBoostUntil, dailyDay/dailyClaimedAt), relays pose / equipped soda / aura / avatar, feeds the Top Soda / Top Rebirths boards (`onLeaderboard` -> lobby.js). Never throws; offline without a server. `src/remotePlayers.js` draws the other players (name tag + their held soda via `HeldCan.fixedKind`). `state.now()` is the server-corrected clock (daily rewards, soda boost). Server URL per channel: `VITE_SERVER_URL_DEV` / `_MAIN` (`SERVER_URL` in config.js); empty = the Bloxity SDK resolves it. Backend id lists/bounds (`SODA_IDS`, `AURA_IDS`, `WORLD_BOUNDS`) are kept in step by hand.
- Avatar flow (main.js): fallback character immediately -> `loadBaseCharacter` + equipped cosmetics/proportions on auth/customizer change.

- Deploy: `.github/workflows/deploy.yml` builds and uploads to Bloxity on push (`main` = prod channel, `dev` = dev channel). Needs `LEGION_GAME_ID` (repo variable or secret) and `LEGION_DEPLOY_TOKEN` (secret); optional `SERVER_URL_DEV` / `SERVER_URL_MAIN` (variable or secret) to pin the backend socket URL instead of SDK resolution.
